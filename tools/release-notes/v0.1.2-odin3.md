**The Last of Us Remastered — Android, сборка для AYN Odin 3 (v0.1.2)**

Всё из v0.1.1-odin3 (AMD FSR 1.0, датчики движения, исправление декодера роликов) плюс:

### Быстрое пробуждение потоков игры (только версия игры 01.11)
Перенесено из Android-порта Uncharted (тот же движок Naughty Dog). Потоки задач игры просыпаются сразу, как появляется работа, вместо ожидания до 10 мс:
- 2 холостых цикла перед сном вместо 1000 (на ARM каждый такой цикл долгий и держал ядро);
- ожидание 1 мс вместо 10;
- пробуждение потоков, когда возобновляется приостановленная задача (раньше их никто не будил).

Ожидается больше FPS и меньше рывков без лишнего нагрева; может помочь и с зависанием после катсцен.
- **Где:** Настройки → CPU и производительность → «Быстрое пробуждение потоков игры» (включено по умолчанию).
- **Как выключить:** отключите этот пункт и перезапустите игру.

## Установка
Если стоит v0.1.1-odin3 — ставьте поверх, сейвы сохранятся. Если стоит оригинальная сборка автора — сначала экспортируйте сейвы и удалите её.

---
**English:** Adds "Fast wake-up for game threads" for game version 01.11 (ported from the Uncharted Android port: 2 spins, 1 ms wait, wake on fiber resume). On by default; Settings → CPU and performance. Installs over v0.1.1-odin3.
