**The Last of Us Remastered — Android, сборка для AYN Odin 3 (v0.1.3)**

Всё из v0.1.2-odin3 (FSR 1.0, датчики движения, быстрое пробуждение потоков) плюс:

### Новый лаунчер
Пять вкладок вместо четырёх, всё по темам: **Главная · Графика · Производительность · Управление · Система**. Под каждой настройкой — пояснение, за что она отвечает. Весь интерфейс переведён на русский (и ещё 9 языков); язык выбирается в «Система → Язык приложения», по умолчанию — язык телефона.

### Ролики дешевле для процессора
Катсцены-видео (1080p) теперь уменьшаются до 720p за один проход фильтром NEON прямо из декодера — без двух лишних проходов swscale. Портировано из Android-порта Uncharted (там масштабирование через swscale занимало ~8 мс из 16,7 мс кадра). Меньше нагрев во время катсцен, картинка та же. Отключается переменной `GOW3_MOVIE_AREA=0` (для отладки).

### Экономичное ожидание потоков (опция)
Производительность → «Экономичное ожидание потоков (меньше нагрев)». Когда поток игры крутится в ожидании другого, процессор засыпает (инструкция WFE), а не жжёт энергию. Тоже из порта Uncharted. **Выключено по умолчанию** — включите и сравните FPS и температуру; если FPS упал, выключите.

## Установка
Ставится поверх v0.1.2-odin3 / v0.1.1-odin3, сейвы сохраняются.

---
**English:** New launcher layout (Home, Graphics, Performance, Controls, System) with an explanation under every option, fully translated. 1080p movies are area-filtered to 720p in one NEON pass (from the Uncharted Android port). Optional "Economical thread waiting" (guest PAUSE → WFE), off by default.
