**The Last of Us Remastered — Android, сборка для AYN Odin 3 (v0.1.4)**

Всё из v0.1.3-odin3 плюс:

### Быстрый режим CPU без TSO (эксперимент, выключен по умолчанию)
Производительность → «Быстрый режим CPU без TSO (экспериментально)». FEX перестаёт эмулировать строгий порядок памяти x86 — код игры (логика, физика, задачи движка) выполняется быстрее, без повышения частот. Сам FEX предупреждает, что это может ломать многопоточные программы: возможны зависания, странные объекты, вылеты. Включайте для короткой проверки; если что-то не так — выключите. В логе видно состояние: `tso=on` или `tso=OFF`.

### Меньше лишней записи в лог
Каждое движение стика писалось строкой в лог (~14 строк в секунду). Теперь эти строки отключены — ввод работает как раньше.

## Установка
Поверх v0.1.3-odin3, сейвы сохраняются.

**English:** Experimental "Fast CPU mode without TSO" (FEX_TSOENABLED=0), off by default; the pad-file log spam is silenced (GOW3_PAD_QUIET=1); the log names the TSO state.
